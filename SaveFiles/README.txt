These are two game files that used the grinding script at the beginning of the game after all characters have joined the party.  The game is still in the prolog and hasn't gone for into the game.  One file is all characters maxed out to level 99, while the other is halfway there to level 50.  The main character is named Tiz, from the first Bravely Default game.

SaveGameData1.sav : Level 99 characters
SaveGameDate2.sav : Level 50 characters

Place the files in your save folder.  If you got the game off of Steam, the default path will likely be:
C:\Users\%USERNAME%\Documents\My Games\Bravely_Default_II\Steam\<numbers>\Saved\SaveGames

Grab the AutoHotKey script to grind and level up:
https://github.com/ClassicAdam/Bravely_Default_II_Grinding_Script_AHK

Thank you and enjoy!
